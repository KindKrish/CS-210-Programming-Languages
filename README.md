# CS 210 Programming Languages Portfolio

## Corner Grocer Project Three

### 1. Summarize the project and what problem it was solving.

For this project, I developed a C++ program for a grocery store called Corner Grocer. The purpose of the program was to help the store track how frequently different items were purchased throughout the day. The program reads a list of grocery items from a file, counts how many times each item appears, and allows users to view the results. This helps the store understand which products are purchased most often.

### 2. What did you do particularly well?

I believe I did well organizing the program and creating a menu that allows users to choose different options. I also learned how to use C++ maps to store grocery items and their frequencies. I focused on making the program understandable and keeping the output organized so users could easily find the information they needed.

### 3. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

One improvement I could make is adding better input validation to prevent errors when users enter unexpected values. I could also improve how the program handles missing files or incorrect file information. These changes would make the program more reliable and easier to maintain. In the future, I would also like to improve the menu design.

### 4. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

The most challenging part was understanding how to read information from a file and count the frequency of each grocery item. I had to review how loops, maps, and file handling work together. Breaking the code into smaller sections helped me understand the process better. I also used course materials and programming examples to help me troubleshoot problems.

### 5. What skills from this project will be particularly transferable to other projects or coursework?

The skills I learned from this project include using C++, working with files, creating functions, using loops, and organizing data with maps. These are skills I can apply to other programming assignments and future software development projects. I also gained more experience with debugging and problem-solving.

### 6. How did you make this program maintainable, readable, and adaptable?

I worked on keeping my code organized by separating different tasks into functions and using meaningful variable names. This makes the program easier to read and understand. Organizing the code this way also makes it easier to update individual parts without having to gimchange the entire program. I believe these practices will help me write better code in future projects.
